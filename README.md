# Аналитик / Методолог: комплект артефактов

Пакет для роли «аналитик процессов / методолог»: карта процесса, регламенты, матрица ответственности,
обучающий пакет. Все артефакты сделаны на одном сквозном примере — выдача доступа и выпуск ЭЦП, —
чтобы было видно, как один процесс проходит путь «описание → регламент → обучение → контроль».

## Состав

| Файл | Что это |
|---|---|
| `process-map.md` | карта процесса AS-IS/TO-BE: шаги, роли, сроки, проблемы, метрики |
| `regulations/reglament-vydachi-dostupa.md` | регламент выдачи доступа: цель, область, роли, порядок, ответственность |
| `regulations/reglament-vypuska-ecp.md` | регламент выпуска ЭЦП: идентификация, акт, реестр |
| `RACI.md` | матрица ответственности по шагам процесса |
| `training-package.md` | обучающий пакет: инструкция, чек-лист, тест на 8 вопросов |

## Как это связано между собой

```
process-map.md  →  BPMN (portfolio/system-analysis/bpmn)  →  ТЗ (system-analysis)
      ↓                                                        ↓
регламенты (что делать)                                   US-истории (что автоматизировать)
      ↓
RACI (кто отвечает) + training-package (как научить)
```

Ключевая мысль комплекта: регламент без обучения не работает, обучение без матрицы ответственности
не приживается, а матрица без метрик не проверяется. Поэтому артефакты идут связкой, а не по одному.

## Что проверяет наниматель

- Есть ли структура у регламента (не «текст в три абзаца»).
- Отличает ли автор процесс от процедуры и роль от должности.
- Есть ли метрики и точки контроля, а не только «надо делать так».
- Умеет ли автор сжать 20 шагов в один читаемый документ.
